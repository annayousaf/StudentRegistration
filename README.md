# Student Registration (Lab Task 03)

Mobile Application Development Lab, University of Azad Jammu and Kashmir
Instructor: Engr. Fahad Nisar

A student registration form built with Jetpack Compose. It covers input, state and events.

## Features
- Text fields: full name, roll number, email (email keyboard)
- Programme dropdown
- Study mode radio group (On campus / Online)
- Interests checkboxes
- Course updates switch
- Weekly study hours slider (0 to 20)
- Validation, Register and Reset buttons

## How to run
1. Open the project in Android Studio.
2. Wait for Gradle sync to finish.
3. Run the app on an emulator or an Android device.
